# Test Resources

Place sample tax documents here for integration testing.

## Expected file types
- PDF, JPG, PNG — scanned appeal forms or assessment notices
- The app accepts these via the upload page (base64-encoded and sent to Claude)

## Naming convention
- `notice_of_assessment_*.pdf` — Form 11 or equivalent notice from assessor
- `appeal_form_*.pdf` — Blank or filled Form 130 / equivalent
- `supporting_*.pdf` — Comparable sales, damage photos, repair estimates
